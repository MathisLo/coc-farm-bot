# Icônes fonctionnelles
Famille SVG 24 × 24, contour 1,75, extrémités et jointures arrondies. Graphismes fonctionnels composés pour ce kit ; aucune dépendance ni CDN.

Les fichiers individuels ont un contour bleu-gris pour une utilisation directe en `<img>`. Pour les recolorer, utiliser `.coc-icon` avec un masque CSS, ou les symboles du sprite dont le contour utilise `currentColor`.

Exemple (chemin à adapter) :
```html
<span class="coc-icon" style="--coc-icon: url('assets/icons-ui/play.svg')" aria-hidden="true"></span>
```
Ne pas remplacer les illustrations des ressources par ces pictogrammes. Les PNG de `assets/resources/` sont les illustrations de la maquette.
